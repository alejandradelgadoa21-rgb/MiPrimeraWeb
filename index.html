Sobre el Proyecto

Construyendo mi primer sitio en la web

Este proyecto nació como parte de las actividades prácticas para dominar el desarrollo web con HTML5 y CSS3, aplicando el flujo de trabajo profesional con Git desde la terminal y publicándolo en internet mediante GitHub Pages.

Además de estructurar código limpio y accesible, este espacio destaca una cuidada selección de animales fascinantes (Mapache, Okapi, Kiwi, Pudú, Puma y Equidna) vinculados a sus fuentes enciclopédicas oficiales en Wikipedia.
